# Inditex – Integrated Financial Model

An integrated financial modeling project built in Excel for Inditex, covering 3 models:

* 3-Statement Financial Model
* Discounted Cash Flow (DCF)
* Leveraged Buyout (LBO)

## Project Overview

The model integrates historical financial statements with operating forecasts and valuation frameworks.

### 1. 3-Statement Model

* Income Statement
* Balance Sheet
* Cash Flow Statement
* Supporting schedules for PP&E, intangible assets, leases, D&A and equity-method investments

### 2. DCF

* Unlevered Free Cash Flow
* WACC / CAPM
* Terminal Value
* Enterprise Value
* Equity Value
* Implied Share Price
* WACC / Terminal Growth sensitivity analysis

### 3. LBO

* Transaction assumptions
* Sources & Uses
* Debt financing
* Debt repayment and cash sweep
* Exit valuation
* Sponsor returns
* MOIC and IRR
* Entry / Exit leverage
* Entry / Exit multiple sensitivity

## Model Structure

| Sheet                | Description                                    |
| -------------------- | ---------------------------------------------- |
| Cover                | Project overview                               |
| Assumptions          | Key operating and valuation assumptions        |
| Historical Data      | Historical financial data                      |
| 3-Statement          | Integrated financial statements                |
| Supporting Schedules | PP&E, intangibles, leases, D&A and investments |
| DCF                  | Discounted Cash Flow valuation                 |
| LBO                  | Leveraged Buyout analysis                      |

## Key Modeling Concepts

The project focuses on understanding the links between:

**Financial Statements → Cash Flow → Valuation → Returns**

The DCF connects operating performance to intrinsic valuation, while the LBO analyzes how leverage, debt paydown and exit valuation affect sponsor returns.

## Data Sources

Historical financial information is based primarily on Inditex annual reports. Market assumptions used in the valuation models are based on publicly available market data.
